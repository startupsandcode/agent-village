Access and setup

Explore the workflow. Know what it takes to start.

Agent Village's public pages introduce the team and explain a design-led route from an agreed goal to reviewable proof. The Workflow controls are a demonstration; they do not launch agents or publish a site.

Real work requires repository access. The Agent Village GitHub repository and issue queue are private. This public website cannot start a mission or grant repository access.
01

What you can explore here

The team demo uses sample activity to introduce the Village. The Workflow page explains the intended Maya, Susie, Sam, and Quinn handoffs. Its buttons only illustrate retry, cancellation, and reset behavior.

02

What a real start requires

  • Access to the private startupsandcode/agent-village repository.
  • A local checkout open in VS Code with Codex, plus GitHub access for the issue and pull request workflow.
  • An agreed GitHub Issue and acceptance criteria before implementation begins.

Available automation and provider setup depend on the authorized environment. This public site does not offer self-service agent runs, repository invitations, or deployment access.

03

Access is not self-service

There is no public request-access form or published contact route on this site. If you do not already have repository access, these pages do not provide a way to start a real mission.
